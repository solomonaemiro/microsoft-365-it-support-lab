# Tenant & Licensing

## Microsoft 365 Tenant

The Apex Services Lab environment was built in a dedicated Microsoft 365 tenant using the fictional organization name Apex Services Lab.

The tenant provided the cloud environment used throughout the project for Microsoft 365 administration, Exchange Online, collaboration services, Microsoft Entra ID, and Intune.

Tenant: apexserviceslab.onmicrosoft.com

![Microsoft 365 Tenant Admin Center](../images/01%20mirco%20365%20tenant%20admin%20center.png)

Evidence: Microsoft 365 Admin Center showing the Apex Services Lab tenant environment.

## Microsoft 365 Business Premium

The lab used a Microsoft 365 Business Premium subscription as the primary license for the environment.

Business Premium provided the Microsoft 365 services required for the project, including the identity, collaboration, and endpoint-management capabilities used in the lab.

![Microsoft 365 Business Premium Subscription](../images/02%20%20%20Business%20premieum%20subscription.png)

Evidence: Microsoft 365 Admin Center showing the Business Premium subscription available in the Apex Services Lab tenant.

## Tenant Foundation

The tenant and subscription formed the foundation for the remainder of the lab.

The environment was subsequently populated with:

- User accounts and department information
- Distribution and security groups
- Microsoft 365 Groups and Teams
- Exchange Online mailboxes and shared resources
- OneDrive and SharePoint resources
- Microsoft Entra ID joined Windows devices
- Microsoft Intune enrollment and management policies

This provided a single controlled environment in which the project's Microsoft 365 administration and IT Support scenarios could be performed and verified.
