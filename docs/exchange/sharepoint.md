# SharePoint

Microsoft SharePoint was used in the lab for organizational document storage and collaboration within the IT Operations environment.

The project included an existing SharePoint team site and the creation of a dedicated document library for IT Support documentation.

## IT Operations SharePoint Site

The IT Operations SharePoint site was created as the team's organizational collaboration site.

![IT Operations SharePoint Site](../images/29%20%20%20IT%20Operations%20sharepoint%20site.png)

Evidence: IT Operations SharePoint site used for organizational collaboration and document management.

## IT Support Documents Library

A dedicated IT Support Documents document library was created within the existing IT Operations SharePoint site.

This provided a structured location for storing IT Support documentation without creating a duplicate SharePoint site.

![IT Support Documents Library Created](../images/81%20IT%20Support%20Documents%20Library%20created.png)

Evidence: IT Support Documents library created within the existing IT Operations site.

## Document Storage Test

A test Word document named IT Support Procedures was added to the new library to verify that documents could be stored successfully.

![IT Support Documents Library File Test](../images/82%20IT%20Support%20Documents%20Library%20File%20Test.png)

Evidence: IT Support Procedures document stored in the IT Support Documents library.
