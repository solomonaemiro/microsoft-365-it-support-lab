# Microsoft 365 IT Support & Administration Lab

## Level 1 — Microsoft 365 Support, Exchange Online & Collaboration
## Phase 2 — Microsoft Entra ID & Intune Endpoint Management

Apex Services Lab is a controlled Microsoft 365 environment built to simulate the day-to-day administration, support, and troubleshooting activities performed by an IT Support or Service Desk technician.

The lab uses a fictional organization, Apex Services, with users, departments, shared resources, collaboration services, and managed Windows devices.

## What This Lab Covers

The project provides hands-on practice with:

- Microsoft 365 user and license administration
- Exchange Online mailboxes and email troubleshooting
- Shared mailboxes, aliases, distribution groups, and resource mailboxes
- Outlook, OneDrive, SharePoint, and Microsoft Teams
- Microsoft Entra ID identity and device management
- Microsoft Intune device enrollment and management
- Windows device compliance and configuration
- Application deployment through Intune
- User onboarding, password resets, access troubleshooting, and offboarding
- Microsoft 365 service and collaboration troubleshooting

## Support Workflow

The lab follows a practical support cycle:

Learn → Build → Test → Break → Troubleshoot → Document

The goal was not simply to configure Microsoft 365 services and record the final configuration.

Instead, the environment was used to simulate realistic support situations. Where appropriate, working configurations were intentionally changed or removed to reproduce a user-facing problem. The issue was then investigated, diagnosed, corrected, and verified.

The support process follows:

User Request → Investigation → Technical Diagnosis → Corrective Action → Verification → Technician Resolution

Each support scenario is documented with evidence from the actual lab environment.

## Project Objective

The objective of this project is to demonstrate practical, entry-level Microsoft 365 administration and troubleshooting skills relevant to IT Support and Service Desk roles.

The project focuses on the ability to:

- Support users and Microsoft 365 services
- Investigate access and configuration problems
- Troubleshoot email and collaboration issues
- Manage users, groups, licenses, and permissions
- Support Windows devices through Microsoft Intune
- Diagnose device compliance and configuration issues
- Perform common onboarding and offboarding tasks
- Apply controlled technical fixes
- Verify that issues have been resolved
- Document technical work clearly and with supporting evidence

## Lab Scope

This is a hands-on training lab, not a production Microsoft 365 environment.

Apex Services and its users are fictional and were created specifically for learning and portfolio demonstration. The support incidents are controlled scenarios designed to demonstrate troubleshooting methodology and technical understanding.

The documentation distinguishes between:

- Configuration — what was built and configured
- Testing — how functionality was verified
- Troubleshooting — how controlled problems were investigated
- Resolution — what corrective action was taken
- Evidence — screenshots demonstrating the actual lab state
