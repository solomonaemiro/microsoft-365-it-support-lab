# Ticket 7 — Calendar Delegation

## Users

David Wilson — General Manager  
Jennifer Thomas — Operations Manager

## Request

> "Please give Jennifer access to manage my calendar and verify that the delegation works."

## Configuration

Calendar delegation was configured for David Wilson's calendar.

Jennifer Thomas was assigned delegated calendar-management access.

![David Wilson Calendar Delegation](../images/18%20David%20wilson%20calendar%20delegation.png)

Evidence: Calendar delegation configured for David Wilson and Jennifer Thomas.

## Investigation

The delegation configuration was reviewed to confirm that Jennifer had the expected access to David's calendar.

The configuration was then tested from the user perspective rather than relying only on the administrative setting.

## Verification Test

Jennifer accessed the delegated calendar and performed a calendar action to verify that the configured permissions were working.

![Jennifer Calendar Delegation Test](../images/26%20Jennifer%20Calendar%20Delegation%20Test.png)

Evidence: Actual calendar delegation test performed by Jennifer Thomas.

The test confirmed that Jennifer could manage David Wilson's calendar as configured.

## Resolution

The requested calendar delegation was successfully configured and verified.

No corrective action was required because the delegation configuration was functioning as expected.

## Technician Resolution

> Configured calendar delegation for Jennifer Thomas on David Wilson's calendar and verified that Jennifer could access and manage the delegated calendar successfully.
