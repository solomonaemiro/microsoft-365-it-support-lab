# Ticket 11 — SharePoint Document Library

## User

Emily Carter — IT Support Technician

## Request

> "We need a dedicated location in SharePoint for storing IT Support documentation. Please create a document library and verify that we can store documents there."

## Investigation

The existing IT Operations SharePoint team site was reviewed.

Rather than creating another SharePoint site or duplicate folder structure, a dedicated document library was created within the existing IT Operations site.

## Document Library

A document library named:

IT Support Documents

was created for organizational support documentation.

![IT Support Documents Library Created](../images/81%20IT%20Support%20Documents%20Library%20created.png)

Evidence: IT Support Documents library created within the IT Operations SharePoint site.

## Document Test

A test Word document named:

IT Support Procedures

was added to the new document library.

The document was used to verify that the library could store IT Support documentation successfully.

![IT Support Documents Library File Test](../images/82%20IT%20Support%20Documents%20Library%20File%20Test.png)

Evidence: IT Support Procedures document stored in the IT Support Documents library.

## Verification

The document library and test file were verified after creation.

The successful file test confirmed that the new library was available for storing organizational support documentation.

## Resolution

Created the IT Support Documents SharePoint document library within the existing IT Operations site and verified its functionality by adding the IT Support Procedures test document.

## Technician Resolution

> Created a dedicated IT Support Documents library within the existing IT Operations SharePoint site and verified that support documentation could be successfully stored in the new library.
