# Ticket 13 — Mailbox Conversion

## User

Laura Wilson — Finance Officer

## Request

> "Laura's mailbox needs to be retained for continued access to the existing email data. Please convert the mailbox to a shared mailbox."

## Investigation

Laura Wilson's user mailbox was reviewed before conversion.

The mailbox-conversion option was selected as part of a controlled employee-lifecycle scenario.

![Laura Wilson Mailbox Conversion Option](../images/20%20laura%20wilson%20mailbox%20converstion%20option.png)

Evidence: Mailbox conversion option for Laura Wilson.

## Resolution

Laura Wilson's mailbox was converted from a user mailbox to a shared mailbox.

The user account was retained in the lab, and the license was not removed at the time of conversion. This allowed the mailbox-preservation step to be documented separately from the later employee-offboarding process.

![Laura Wilson Converted Shared Mailbox](../images/21%20laura%20wilson%20converted%20shared%20mailbox.png)

Evidence: Laura Wilson's mailbox after conversion to a shared mailbox.

## Verification

The mailbox was reviewed after conversion to confirm that the conversion had completed successfully and that the mailbox was now represented as a shared mailbox.

The converted mailbox was subsequently used in the employee offboarding and internal forwarding scenarios.

## Technician Resolution

> Converted Laura Wilson's user mailbox to a shared mailbox as part of the mailbox-preservation process. Verified the converted mailbox and retained the user account for the subsequent controlled offboarding workflow.
