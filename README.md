# Microsoft 365 IT Support & Administration Lab

Hands-on Microsoft 365 lab built to simulate Level 1 IT Support and junior Microsoft 365 administration within a fictional organization, Apex Services Lab.

## The project follows:

Learn → Build → Test → Break → Troubleshoot → Document

## What I Practiced

- Microsoft 365 user and license administration
- Exchange Online and Outlook support
- Shared mailboxes, aliases, distribution groups, and resource mailboxes
- Microsoft Entra ID and Windows device management
- Microsoft Intune enrollment, compliance, configuration, and application deployment
- SharePoint, OneDrive, and Microsoft Teams
- User onboarding, password resets, access troubleshooting, and offboarding
- Evidence-based technical documentation

## Support Scenarios

Completed 16 hands-on support scenarios covering common Microsoft 365 and IT Support issues, including email delivery, permissions, licensing, user lifecycle, Teams access, resource booking, and Intune compliance.

Each scenario documents the user issue, investigation, diagnosis, corrective action, verification, and supporting evidence.

## Environment

- Microsoft 365 Business Premium
- Microsoft Entra ID
- Exchange Online
- Microsoft Intune
- Microsoft Teams
- SharePoint
- OneDrive
- Outlook
- Windows 10 Pro

«This is a controlled training lab using fictional users, devices, and organizational data. It is not a production environment.»
